War Loss Analysis Dashboard

An end-to-end data analytics project focused on analyzing war-related losses and identifying trends through Python, PostgreSQL and Power BI.

The project aims to transform raw conflict-related data into structured analytical insights and interactive visualizations, making it easier to explore loss patterns over time and across different categories.

Project Objectives

Analyze historical war-related loss data.

Identify trends and changes in reported losses over time.

Explore variations across loss categories.

Use SQL to organize and analyze structured data.

Build interactive Power BI dashboards for data exploration.

Communicate findings through meaningful visualizations.

Project Workflow

Data Collection: Obtain and examine the source dataset.

Data Exploration: Understand data structure, variables and quality.

Data Cleaning: Handle missing values, inconsistencies and formatting issues.

Database Management: Store structured data in PostgreSQL.

SQL Analysis: Investigate trends and aggregate relevant metrics.

Visualization: Develop an interactive Power BI dashboard.

Insights: Interpret analytical findings and communicate key patterns.
